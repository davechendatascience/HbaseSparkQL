# HbaseSparkQL

A Connector between Spark & HBase based on the hbase-spark module that allows the Spark Engine to execute distributed queries to HBase similar to native HBase query syntax.

## Modernization & Migration

For details on migrating this project from legacy Spark 1.6 / HBase 2.0-alpha to modern **Spark 3.5.x** and **HBase 2.5.x/2.6.x**, see the [HbaseSparkQL Modernization & Migration Guide](docs/MIGRATION_GUIDE.md).
